# Solution Overview

## The Problem
Supply chain disruptions cause cascading failures. Cold chain breaches spoil high-value cargo.

## Our Solution
We built a "Bob-powered" assistant that:
1. **Real-time Disruption Mapping:** Instantly correlates global events with active shipment routes.
2. **Dynamic Fleet Optimization:** Instead of manual dispatch, Bob suggests the best idle asset for a specific route based on cargo type (e.g., Refrigerated vs Standard).
3. **Predictive Cold Chain Monitoring:** Analyzes IoT logs in real-time. If a temperature excursion occurs, Bob classifies it (e.g., "Minor deviation" vs "Regulatory breach") and alerts before delivery.
